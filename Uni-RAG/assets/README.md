# Manuscript Figures

The three PNG files are 300-dpi renderings cropped from the author-provided revised TKDE manuscript. Their content has not been redrawn or generated.

| File | Manuscript source |
| :--- | :--- |
| `uni_rag_overview.png` | Figure 1, page 2 |
| `uni_rag_architecture.png` | Figure 2, page 4 |
| `uni_rag_stem_examples.png` | Figure 3, page 9 |

`figure_manifest.json` records the source pages, crop coordinates in PDF points, rendering resolution, and output dimensions. The original paper captions are replaced only by the surrounding README descriptions; the visual content of the figures is preserved.

Cropping at 300 dpi does not increase the intrinsic detail of raster images embedded in the manuscript. For final publication-quality website assets, original authoring files would be preferable when available. The source PDF itself is not bundled in this repository package.
